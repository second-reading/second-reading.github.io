In one line

A lost 1993 arcade game, full of bugs. Fix them to finish it, and find out why it was never released.

Description

FATAL EXCEPTION is a story game built around a 16-bit-style shoot 'em up. You're restoring a lost arcade prototype from 1993, and it's full of bugs: every crash stops the game and shows you the code that broke it, and you fix it to play on. You don't need to know how to code.

As the game gets further, a mystery opens up: a small company, two friends, a computer show in September 1993, and a stand that stayed empty all weekend.

It plays in the browser, with an original acid house soundtrack, and the shooting is part of the music: every shot lands on the beat, and every kill is the next note up.

What's in it

  • A story you play at your own pace, around a proper shoot 'em up: five stages, bosses, power-ups, a high-score table.
  • No coding knowledge needed: if you can spot what's wrong, you can fix it.
  • Hard enough for shmup fans, with an easy mode and a hands-free mode for everyone else.
  • An arcade mode once you've finished it.
  • An original acid house soundtrack, synthesised live, which is how it all fits on a floppy disk.

Contains flashing lights, with a warning and a reduced-motion option.
